## Introducción

¿Alguna vez quisiste llevar tus proyectos al siguiente nivel dibujando muchas formas con solo unas pocas líneas de código? Imagina dibujar una fila de árboles, una pila de libros, los arcos de un arcoíris o el interior de un panal de abejas. Para crear elementos visuales que están hechos con versiones de la misma forma, vamos más allá de codificar formas individuales y nos aventuramos en el maravilloso mundo de los bucles y los arreglos. ¡Aprendamos cómo crear patrones repetitivos con solo unas pocas líneas de código!

![Una forma de arco y hexágono están alineadas verticalmente con la etiqueta que dice "objeto único". Las flechas apuntan desde estas formas a patrones correspondientes que están alineados verticalmente bajo una etiqueta que dice "objetos multiplicados". El arco único apunta a cinco arcos apilados verticalmente creando una forma de arcoíris. El hexágono apunta a muchos hexágonos dispuestos en un teselado de panal.](../images/introduction/loops-intro.png)

Dibujar cada forma con una nueva línea de código sería un proceso tedioso. En su lugar, podemos usar *bucles*, que nos permiten ejecutar y repetir bloques de código tantas veces como queramos. En este tutorial, usamos bucles y arreglos para crear [un boceto de carrera de orugas](https://editor.p5js.org/gbenedis@gmail.com/sketches/BrmtZ36ET).

![Tres orugas rosadas reptando para alcanzar una línea de meta verde a la derecha del lienzo.](../images/introduction/caterpillar-race-end.gif)

Un grupo de orugas comenzará en la línea de salida de la carrera, y la primera oruga en cruzar la línea de meta gana. ¡La oruga ganadora variará cada vez que ejecutemos el boceto!

En este tutorial, vas a:

- Dibujar y actualizar tareas y formas repetitivas usando *bucles for*
- Usar funciones personalizadas para actualizar variables y estados del programa y hacer cambios en el programa mientras se ejecuta el boceto.
- Usar [sentencias condicionales](/reference/p5/if) y `random()` para generar diferentes resultados
- Ejecutar y detener tu boceto usando disparadores de ratón y [variables booleanas](/reference/p5/Boolean)
- Almacenar las posiciones de las orugas en un arreglo

## Paso 1 – Dibujar la pista de carreras

- Abre un nuevo proyecto en el [Editor Web de p5.js](https://editor.p5js.org/), dale un nombre como "Carrera de Orugas" y guárdalo.
- En `setup()`, crea un lienzo de 500x500 píxeles.
- Declara dos nuevas variables globales encima de `setup()` para definir las coordenadas x de tu línea de salida y línea de meta respectivamente. Nombraremos las dos variables startLine y finishLine.
  - Asígnales valores en el eje x, dependiendo de dónde quieras colocar tus líneas de salida y meta. En este ejemplo, estableceremos startLine en 30 y finishLine en 360.
- En la función `draw()`:
  - Establece un color de fondo. Por ejemplo, lo estableceremos en marrón con `background(121, 96, 76)`;
  - Dibuja un rectángulo y establece su coordenada x como `startLine`. Establece su altura a `height` para que se extienda verticalmente a través del lienzo.
  - Dibuja otro rectángulo en `finishLine` y repite el mismo paso.
  - Rellena los dos rectángulos con diferentes colores.
- No olvides nombrar y guardar tu boceto.

Tu código podría verse así:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;
function setup() {
  // 500x500 canvas
  createCanvas(500, 500); 
}

function draw() {
  //set background color
  background(121, 96, 76);

  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);
}
`} />

## Paso 2 – Dibujar un segmento de oruga y hacerlo mover.

A continuación, dibujaremos un segmento de una oruga en el lienzo y lo haremos viajar desde la línea de salida hasta la línea de meta. Se detendrá al final de la carrera.

- Declara una nueva variable global llamada `circX` y asígnale el valor de `startLine`.
  - Esta será la coordenada x del segmento de la oruga.
- Declara una nueva variable global llamada `circY` y asígnale el valor de 250 (o la mitad de la altura).
  - Esta será la coordenada y del segmento de la oruga.
- En `draw()`:
  - Dibuja el segmento de la oruga usando la función `circle()`. Incluye `circX`, `circY` y 50 como argumentos para especificar la coordenada x, la coordenada y y el diámetro: `circle(circX, circY, 50);`
  - También le daremos al círculo un color de relleno blanco y un trazo negro delgado.
  - Debajo del comando circle, incrementa `circX` en 20 usando `circX += 20;`
    - Esto significa que cada vez que se ejecuta la función `draw()`, la variable `circX` aumentará en 20 píxeles. El boceto dibujará un nuevo círculo en una coordenada x 20 píxeles a la derecha del círculo anterior creando la forma de una oruga.
- Agrega la siguiente sentencia condicional al final de `draw()`:

  ```js
  if (circX > finishLine) {
    noLoop();
  }
  ```

La función `noLoop()` detiene la ejecución de la función `draw()`. La sentencia `if` detiene `draw()` usando `noLoop()` cuando la coordenada x del círculo supera el valor de finishLine. Visita la referencia de p5.js para más información sobre [`noLoop()`](/reference/p5/noLoop).

En `setup()`, agrega: `frameRate(3);`

- Un [frame rate](/reference/p5/frameRate) es el número de veces que `draw()` se ejecuta en un segundo. Establecerlo en un número bajo hará que los movimientos sean más notorios y dramáticos para esta animación.

Tu código debería verse así:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;

// Set variables to draw circles starting point.
let circX = startLine;

let circY = 250;

function setup() {
  createCanvas(500, 500); 

  // Set a slow frame rate.
  frameRate(3);
}

function draw() {
  // Draw the background.
  background(121, 96, 76);

  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);

  // Draw a circle.
  fill(255);
  stroke(0);
  circle(circX, circY, 50);

  // Move the x-coordinate
  // to the right.
  circX += 20;

  // End the loop when x
  // reaches the finish line.
  if (circX > finishLine) {
    noLoop();
  }
}
`} />

### [Sentencias if](/reference/p5/if)

Las sentencias if, como la aplicada anteriormente, se refieren a bloques de código que se ejecutan solo cuando una condición dada es verdadera. Normalmente se escriben:

```js
if (<condición>) {
  <código>
}
```

La condición se especifica dentro de los paréntesis de la sentencia if. Las llaves `{ }` marcan el inicio y el final del bloque de código. En el Paso 2, la condición `circX > finishLine` detiene la ejecución de `draw()` cuando la coordenada x del círculo es mayor que el valor de `finishLine` llamando a `noLoop()`.

Visita la referencia de p5.js para [if](/reference/p5/if) para aprender más.


## Paso 3 – Dibujar una oruga

Repetiremos el segmento de oruga del Paso 2 para hacer una fila de círculos que forman el cuerpo de la oruga. Usaremos un *bucle for* para dibujar múltiples círculos en una fila.


### 3.1 – Declarar las propiedades del cuerpo de la oruga

Encima de `setup()`:

- Declara una nueva variable llamada `segments` y asígnale un valor de 6.
  - Esta variable define cuántos círculos componen el cuerpo de la oruga.
- Declara una nueva variable llamada `spacing` y asígnale un valor de 20.
  - Esta variable define el espaciado en píxeles entre los segmentos del cuerpo de la oruga.
- Declara una nueva variable llamada `segmentSize` y asígnale un valor de 50.
  - Esta variable define el diámetro de los segmentos circulares del cuerpo.


### 3.2 – Construir el cuerpo de la oruga con un *bucle for*

En `draw()`:

- Después del código que dibuja la línea de meta, declara una nueva variable local `x` para posicionar todos los segmentos del cuerpo: `let x = circX;`
- Agrega un *bucle for* usando: `for (let i = 0; i < segments; i += 1) { }`
  - Un *bucle for* repetirá el código que escribimos dentro de las llaves múltiples veces.
  - Mueve las líneas de código que dibujan el `circle()` dentro de las llaves del *bucle for*.
- Después del bucle for, agrega: `circX += spacing`
  - Esto mueve el cuerpo de la oruga hacia la derecha cada vez que se ejecuta `draw()`.

Tu código debería verse así:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;

// Set variables for the caterpillar.
let circX = startLine;
let circY = 250;
let spacing = 20;
let segments = 6;
let segmentSize = 50;

function setup() {
  createCanvas(500, 500);

  // Set a slow frame rate.
  frameRate(3);
}

function draw() {
  // Draw the background.
  background(121, 96, 76);

  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);

  // a local variable to position the body segments
  let x = circX;

  // draw multiple circles (caterpillar body)
  for (let i = 0; i < segments; i += 1) {
    // Draw a circle.

    fill(255);
    stroke(0);
    circle(x, circY, segmentSize);
    x += spacing;
  }

  // Move the caterpillar  to the right.
  circX += spacing;
  // stop the animation  when x
  // reaches the finish line.
  if (circX > finishLine) {
    noLoop();
  }
}
`} />


### [Bucles for](/reference/p5/for)

Un bucle for puede ejecutar una sección (o bloque) de código múltiples veces. Los bucles for se pueden escribir así:

```js
for (let i = 0; i < number; i += 1) { 
  // código que quieres ejecutar number veces
}
```

Dentro de las llaves `{}` de un bucle for, escribimos el código que queremos ejecutar repetidamente. Podemos especificar el número de veces que queremos que el código se repita estableciendo la condición del bucle.

Un bucle for se define por tres expresiones dentro de sus paréntesis, cada una separada por punto y coma. Son:

<AnnotatedLine code={({ bottom }) => `for (${bottom('init', ' let i = 0; ')} ${bottom('cond', 'i < number;')} ${bottom('instr', '  i += 1  ')}) { }`}>
  <Fragment slot="init">Inicialización</Fragment>
  <Fragment slot="cond">Condición</Fragment>
  <Fragment slot="instr">Instrucción</Fragment>
</AnnotatedLine>

- **Inicialización**: inicializa la variable de iteración `i` con un número para comenzar a contar.

  ```js
  let i = 0;
  ```

- **Condición:** la condición que mantiene el bucle en ejecución. Mientras esta condición sea verdadera, el bucle for continuará ejecutándose. Cuando esta condición sea `false`, el bucle for se detendrá.

  ```js
  i < number;
  ```

- **Instrucción:** esto le dice al programa cómo cambiar el número de conteo cada vez que se ejecuta el bucle.

  ```js
  i += 1;
  ```

La primera expresión, `let i = 0`, inicializa o comienza el bucle for.

- i es una variable que define el estado inicial del bucle for. También se conoce como la variable de *índice*. Comúnmente, el índice comienza en un valor de 0 y aumenta en cada ciclo. El nombre de esta variable puede ser cualquiera que desees. Generalmente, se usan variables de una sola letra como `i`, `j` y `k`, pero siéntete libre de usar algo más descriptivo.

La segunda expresión, `i < number`, es la condición para que el bucle siga ejecutándose. Se conoce como una expresión booleana, ya que esta expresión puede devolver `true` o `false`. Mientras esta expresión sea `true`, el bucle for continuará ejecutándose, y en este caso la variable de índice (`i`) continuará aumentando.

- `number` puede ser cualquier valor numérico o variable que almacene un valor numérico. Para contar, a menudo se usan enteros.
  - Ejemplo: `i < 5;` o `i < segments;`
- En este caso, `number` determina el número de veces que se ejecutará el bucle for porque el valor inicial `i` comienza en 0.
- En el ejemplo de la oruga anterior, establecemos este valor a la variable `segments`, que especifica el número de círculos que forman el cuerpo de la oruga. Mientras el índice no haya alcanzado el número almacenado en `segments`, el bucle continuará dibujando círculos.
  - Una vez que el número de círculos dibujados ya no es menor que segments, el programa sale del bucle for y continúa a la siguiente línea de código.

La tercera expresión, `i += 1`, es cómo cambiará el índice al final de cada iteración del bucle.

- Una [**iteración de bucle**](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Loops_and_iteration) se refiere a una sola vez que se ejecuta un bucle. Por ejemplo, si un bucle for se ejecuta 3 veces, tiene 3 iteraciones.
- En este ejemplo, la variable `i` aumentará en 1 cada vez que se ejecute el bucle for. Eso significa que la primera vez que se ejecuta este bucle for, `i` es 0. La segunda vez que se ejecuta el bucle, `i` es 1. La tercera vez que se ejecuta, `i` es 2, y así sucesivamente (hasta que alcance el valor `number`). Esta expresión `i += 1` también se puede escribir `i++`.

En resumen:

1. Cuando un programa ejecuta un bucle for, primero declara la variable de índice del bucle en la primera expresión.
2. Verifica la segunda expresión, que es una expresión booleana. Si es `true`, ejecuta el código escrito dentro de las llaves.
3. Al final de un bucle, el valor de la variable de iteración, `i`, cambia como se define en la tercera expresión.
4. El bucle repite este proceso hasta que la condición en la segunda expresión sea `false`. Cuando la condición es `false`, el programa sale del bucle for y continúa a las siguientes líneas de código en el boceto.

Visita la [referencia de bucles for](/reference/p5/for) para aprender más.


### 3.3 – Agregar más detalles a la oruga

- Ajusta el color `fill()` del cuerpo de tu oruga si lo deseas. En este ejemplo, le daremos un color rosado: `fill(255, 0, 200);`
- Dibuja los ojos de la oruga. La posición de los ojos es la misma que las coordenadas x e y del último círculo dibujado para el cuerpo. Esto significa que viene DESPUÉS de que el bucle for ya haya dibujado todos los círculos, así que agregaremos los ojos después del bucle for, pero antes de `noLoop()`. Esto asegura que los ojos se dibujen encima del último círculo en el cuerpo de la oruga.
  - Declara `eyeSize` como una nueva variable global encima de `setup()` y asígnale el valor de 15.
  - Dibuja dos círculos.
    - Dales un relleno negro y un trazo blanco grueso.
  - Agrega el primer ojo y establece sus coordenadas y tamaño: `circle(x, circY-eyeSize, eyeSize);`
    - Esto coloca el ojo en la parte superior del último círculo dibujado.
  - Agrega el segundo ojo y establece sus coordenadas y tamaño: `circle(x - eyeSize, circY-eyeSize, eyeSize);`
    - Restamos la coordenada x del segundo ojo por `eyeSize` para que ambos ojos estén uno al lado del otro sin superposición.
- Cuando tu oruga esté completa, organiza tu código en una función personalizada llamada `drawCaterpillar()`. ¡Siéntete libre de modificar la oruga como desees!
  - Define la función `drawCaterpillar()` fuera de `draw()`.
  - La función debe incluir tu bucle for de círculos para el cuerpo de la oruga y los dos círculos para los ojos de la oruga.
  - ¡Recuerda llamarla en la función `draw()`! Escribe `drawCaterpillar();` en `draw()` antes de la sentencia if que termina el bucle.

Así es como podría verse tu boceto hasta ahora:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;

// Set variables for the caterpillar.
let circX = startLine;
let circY = 250;
let spacing = 20;
let segments = 6;

let eyeSize = 15;

function setup() {
  createCanvas(500, 500);
  frameRate(3);

## Paso 4 – Generalizar la función `drawCaterpillar()`

Cuando el boceto se ejecuta por primera vez, queremos que cada oruga esté en la línea de salida. Esto significa que necesitaremos agregar parámetros a nuestra función para que podamos modificarlos y especificar dónde se dibujan las orugas.

- Ve a la función `drawCaterpillar()`.
  - Agrega `x` como parámetro en los paréntesis de la función: `function drawCaterpillar(x) { ...}`
    - Ten en cuenta que ya habíamos declarado `x` como una variable local en la función `drawCaterpillar()`. Podemos eliminar esa declaración y usar el parámetro `x` en su lugar.
  - Agrega `y` como segundo parámetro en los paréntesis de la función `function drawCaterpillar(x,y) { ... }`
    - Sustituye `y` por `circY` en el cuerpo de la función.

Puedes aprender más sobre funciones personalizadas, argumentos y parámetros en nuestro tutorial anterior, [Organizando Código con Funciones](/tutorials/organizing-code-with-functions), y la referencia de p5.js para [funciones](/reference/p5/function).

Tu función personalizada ahora debería verse similar a esto:

```js
function drawCaterpillar(x,y) {
  // Create a loop of circles
  // to form the body.
  for (let i = 0; i < segments; i += 1) {
    fill(255, 0, 200);
    stroke(0);
    strokeWeight(1);
    circle(x, y, 50);

    x += spacing;
  }
 
  // Draw the caterpillar's eyes.
  fill(0);
  stroke(255);
  strokeWeight(3);
  circle(x, y - eyeSize, eyeSize);
  circle(x - eyeSize, y - eyeSize, eyeSize);
}
```

- En `draw()`, llama a `drawCaterpillar()` tres veces para obtener tres orugas

Tu función draw debería verse así:

```js
function draw() {
  // Draw the background.
  background(121, 96, 76);
  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);

  // Draw 3 caterpillars.
  drawCaterpillar(circX,circY-150);
  drawCaterpillar(circX,circY);
  drawCaterpillar(circX,circY+150);

  circX += spacing;
  // End the loop when x
  // reaches the finish line.
  if (circX > finishLine) {
    noLoop();
  }
}
```


## Paso 5 – Crear una función `drawCaterpillars()`

Ahora tenemos 3 orugas viajando por la pantalla al mismo tiempo. Podemos usar un bucle para dibujar las tres orugas en lugar de tres llamadas individuales a la función `drawCaterpillar()`.

- Declara una nueva variable global encima de `setup()` en tu boceto para el número de orugas que quieres en la carrera: `let numCaterpillars = 3;`
- Crea una nueva función personalizada fuera de `draw()` y nómbrala `drawCaterpillars()`
  - Haz un nuevo bucle for dentro de la función `drawCaterpillars()`.
    - Inicializa y comienza la variable del bucle en 0 en la primera expresión del bucle.
    - Establece la condición a `i < numCaterpillars` en la segunda expresión del bucle.
    - Incrementa la variable del bucle en la tercera expresión.
  - Llama a `drawCaterpillar(circX, circY);` dentro de las llaves del bucle for.
- En `draw()`, llama a `drawCaterpillars();`

Tus funciones `draw()` y `drawCaterpillars()` deberían verse así:

```js
let numCaterpillars = 3;

// ...declaraciones de variables y setup

function draw() {
  // Draw the background.
  background(121, 96, 76);
  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);

  circX += spacing;

  // Draw the caterpillars on the canvas
  drawCaterpillars();

  // End the loop when x
  // reaches the finish line.
  if (circX > finishLine) {
    noLoop();
  }
}

function drawCaterpillars() {
  for (let i = 0; i < numCaterpillars; i += 1) {
    drawCaterpillar(circX,circY);
  }
}
```

## Paso 6 – Posicionar las orugas para la carrera

**¡Recapitulación!** De los Pasos 3 y 4, tenemos dos funciones personalizadas en nuestro boceto.

- `drawCaterpillar(x,y)` dibuja una oruga usando los parámetros x e y.
- `drawCaterpillars()` llama a la función `drawCaterpillar()` y la coloca dentro de un bucle for para que podamos dibujar múltiples orugas.

Ahora, cada oruga está en las mismas coordenadas x e y. Ajustaremos el código en el bucle for para espaciar las orugas con la coordenada y.

- Ve a la declaración de la función `drawCaterpillars()`.
  - Dentro del *bucle for*, agrega una nueva línea de código: `let padding = height / numCaterpillars;`
    - Esto declara una nueva variable llamada `padding` que determina el espacio vertical entre cada oruga.
    - Le asignamos el valor de la `height` del lienzo, dividido por el número de orugas en el boceto. Esto divide el lienzo verticalmente en filas (una para cada oruga). La altura de cada fila es el valor de `padding`.

    - Usando la variable `i`, cada iteración del bucle for posiciona una oruga en su propia fila
    - Sumar 0.5 a `i` centra la oruga en esa fila.
- Similar al Paso 5, agrega `y` como argumento en los paréntesis de la llamada a la función `drawCaterpillar()`.
  - La línea de código ahora debería ser: `drawCaterpillar(circX, y);`

En resumen, hemos asignado `x` e `y` como parámetros para ser usados dentro de la función `drawCaterpillar()`. Usamos `circX` e `y` como argumentos al llamar esta función en `drawCaterpillars()`.

Puedes aprender más sobre funciones personalizadas, argumentos y parámetros en nuestro tutorial anterior, [Organizando Código con Funciones](/tutorials/organizing-code-with-functions).

### Dibujar con variables de índice de bucles for

La variable de índice de un bucle for (`i`) puede aumentar o disminuir incrementalmente con cada iteración del bucle. En este tutorial, la variable `i` comienza en 0 y aumenta en 1 cada vez que se ejecuta el *bucle for*.

- La primera vez que se ejecuta este bucle for, `i` es 0.
- La segunda vez que se ejecuta el bucle, `i` es 1.
- La tercera vez que se ejecuta, `i` es 2, y así sucesivamente.

Podemos usar variables de índice en nuestros dibujos para sumar, restar, multiplicar y dividir números para que su resultado sea diferente en cada iteración del bucle for.

En este ejemplo, usamos `i` para calcular un espaciado consistente entre cada oruga (ver tabla a continuación):

- Durante la tercera iteración, `i` es 2 e `y` se convierte en `2.5 * padding`. La tercera oruga se dibuja en el nuevo valor de y.

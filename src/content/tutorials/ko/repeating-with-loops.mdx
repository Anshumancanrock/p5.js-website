## 소개

코드 몇 줄만으로 많은 도형을 그려 프로젝트를 한 단계 높이고 싶었던 적이 있나요? 나무 한 줄, 책 더미, 무지개의 아치, 또는 벌집 내부를 그리는 것을 상상해 보세요. 같은 도형의 버전으로 만들어진 비주얼을 만들기 위해, 우리는 개별 도형을 코딩하는 것을 넘어서 루프와 배열의 놀라운 세계로 나아갑니다. 코드 몇 줄만으로 반복 패턴을 만드는 방법을 배워봅시다!

![아치와 육각형 모양이 "단일 객체"라는 레이블과 함께 수직으로 정렬되어 있습니다. 화살표는 이 도형들에서 "복제된 객체"라는 레이블 아래 수직으로 정렬된 해당 패턴을 가리킵니다. 단일 아치는 무지개 모양을 만드는 다섯 개의 수직으로 쌓인 아치를 가리킵니다. 육각형은 벌집 테셀레이션으로 배열된 많은 육각형을 가리킵니다.](../images/introduction/loops-intro.png)

각 도형을 새로운 코드 줄로 그리는 것은 지루한 과정일 것입니다. 대신, 우리는 *루프*를 사용할 수 있으며, 이를 통해 코드 블록을 원하는 만큼 반복 실행할 수 있습니다. 이 튜토리얼에서는 루프와 배열을 사용하여 [애벌레 경주 스케치](https://editor.p5js.org/gbenedis@gmail.com/sketches/BrmtZ36ET)를 만듭니다.

![세 마리의 분홍색 애벌레가 캔버스 오른쪽의 녹색 결승선에 도달하기 위해 기어가고 있습니다.](../images/introduction/caterpillar-race-end.gif)

애벌레 그룹이 경주의 출발선에서 시작하고, 결승선을 먼저 통과하는 애벌레가 승리합니다. 스케치를 실행할 때마다 우승 애벌레가 달라집니다!

이 튜토리얼에서 배울 내용:

- *for 루프*를 사용하여 반복적인 작업과 도형을 그리고 업데이트하기
- 커스텀 함수를 사용하여 변수와 프로그램 상태를 업데이트하고 스케치가 실행되는 동안 프로그램을 변경하기
- [조건문](/reference/p5/if)과 `random()`을 사용하여 다양한 결과 생성하기
- 마우스 트리거와 [불리언 변수](/reference/p5/Boolean)를 사용하여 스케치 실행 및 중지하기
- 애벌레의 위치를 배열에 저장하기

## 1단계 – 경주 트랙 그리기

- [p5.js 웹 에디터](https://editor.p5js.org/)에서 새 프로젝트를 열고, "Caterpillar Race"와 같은 이름을 지정하고 저장하세요.
- `setup()`에서 500x500 픽셀 캔버스를 만드세요.
- `setup()` 위에 두 개의 새 전역 변수를 선언하여 출발선과 결승선의 x 좌표를 각각 정의하세요. 두 변수의 이름을 startLine과 finishLine으로 지정하겠습니다.
  - 출발선과 결승선을 어디에 배치할지에 따라 x축의 값을 할당하세요. 이 예제에서는 startLine을 30, finishLine을 360으로 설정하겠습니다.
- `draw()` 함수에서:
  - 배경색을 설정하세요. 예를 들어, `background(121, 96, 76)`으로 갈색으로 설정하겠습니다;
  - 직사각형을 그리고 x 좌표를 `startLine`으로 설정하세요. 높이를 `height`로 설정하여 캔버스를 수직으로 가로지르도록 하세요.
  - `finishLine`에 다른 직사각형을 그리고 같은 단계를 반복하세요.
  - 두 직사각형을 다른 색으로 채우세요.
- 스케치의 이름을 지정하고 저장하는 것을 잊지 마세요.

코드는 다음과 같을 수 있습니다:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;
function setup() {
  // 500x500 canvas
  createCanvas(500, 500); 
}

function draw() {
  //set background color
  background(121, 96, 76);

  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);
}
`} />

## 2단계 – 애벌레 세그먼트 하나를 그리고 움직이게 하기

다음으로, 캔버스에 애벌레의 세그먼트 하나를 그리고 출발선에서 결승선까지 이동하게 하겠습니다. 경주가 끝나면 멈출 것입니다.

- `circX`라는 새 전역 변수를 선언하고 `startLine`의 값을 할당하세요.
  - 이것이 애벌레 세그먼트의 x 좌표가 됩니다.
- `circY`라는 새 전역 변수를 선언하고 250(또는 높이의 절반)의 값을 할당하세요.
  - 이것이 애벌레 세그먼트의 y 좌표가 됩니다.
- `draw()`에서:
  - `circle()` 함수를 사용하여 애벌레 세그먼트를 그리세요. x 좌표, y 좌표, 지름을 지정하기 위해 `circX`, `circY`, 50을 인수로 포함하세요: `circle(circX, circY, 50);`
  - 원에 흰색 채우기 색상과 얇은 검은색 테두리도 부여하겠습니다.
  - circle 명령 아래에서 `circX += 20;`을 사용하여 `circX`를 20만큼 증가시키세요
    - 이는 `draw()` 함수가 실행될 때마다 변수 `circX`가 20 픽셀씩 증가한다는 것을 의미합니다. 스케치는 이전 원의 오른쪽 20 픽셀에 새 원을 그려 애벌레 모양을 만듭니다.
- `draw()`의 끝에 다음 조건문을 추가하세요:

  ```js
  if (circX > finishLine) {
    noLoop();
  }
  ```

`noLoop()` 함수는 `draw()` 함수가 다시 실행되는 것을 중지합니다. `if` 문은 원의 x 좌표가 finishLine의 값을 넘으면 `noLoop()`를 사용하여 `draw()`를 중지합니다. [`noLoop()`](/reference/p5/noLoop)에 대한 자세한 정보는 p5.js 레퍼런스를 방문하세요.

`setup()`에 다음을 추가하세요: `frameRate(3);`

- [프레임 레이트](/reference/p5/frameRate)는 `draw()`가 1초에 실행되는 횟수입니다. 낮은 숫자로 설정하면 이 애니메이션의 움직임이 더 눈에 띄고 극적으로 보입니다.

코드는 다음과 같아야 합니다:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;

// Set variables to draw circles starting point.
let circX = startLine;

let circY = 250;

function setup() {
  createCanvas(500, 500); 

  // Set a slow frame rate.
  frameRate(3);
}

function draw() {
  // Draw the background.
  background(121, 96, 76);

  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);

  // Draw a circle.
  fill(255);
  stroke(0);
  circle(circX, circY, 50);

  // Move the x-coordinate
  // to the right.
  circX += 20;

  // End the loop when x
  // reaches the finish line.
  if (circX > finishLine) {
    noLoop();
  }
}
`} />

### [If 문](/reference/p5/if)

위에서 적용한 것과 같은 if 문은 주어진 조건이 참일 때만 실행되는 코드 블록을 나타냅니다. 일반적으로 다음과 같이 작성됩니다:

```js
if (<조건>) {
  <코드>
}
```

조건은 if 문의 괄호 안에 지정됩니다. 중괄호 `{ }`는 코드 블록의 시작과 끝을 표시합니다. 2단계에서 조건 `circX > finishLine`은 원의 x 좌표가 `finishLine`의 값보다 클 때 `noLoop()`를 호출하여 `draw()`의 재실행을 중지합니다.

더 자세히 알아보려면 p5.js 레퍼런스의 [if](/reference/p5/if)를 방문하세요.


## 3단계 – 애벌레 하나 그리기

2단계의 애벌레 세그먼트를 반복하여 애벌레 몸체를 구성하는 원의 행을 만들겠습니다. 한 줄에 여러 원을 그리기 위해 *for 루프*를 사용하겠습니다.


### 3.1 – 애벌레 몸체의 속성 선언하기

`setup()` 위에:

- `segments`라는 새 변수를 선언하고 6의 값을 할당하세요.
  - 이 변수는 애벌레의 몸체를 구성하는 원의 수를 정의합니다.
- `spacing`이라는 새 변수를 선언하고 20의 값을 할당하세요.
  - 이 변수는 애벌레 몸체 세그먼트 사이의 픽셀 간격을 정의합니다.
- `segmentSize`라는 새 변수를 선언하고 50의 값을 할당하세요.
  - 이 변수는 원형 몸체 세그먼트의 지름을 정의합니다.


### 3.2 – *for 루프*로 애벌레 몸체 만들기

`draw()`에서:

- 결승선을 그리는 코드 뒤에, 모든 몸체 세그먼트의 위치를 지정하기 위한 새 로컬 변수 `x`를 선언하세요: `let x = circX;`
- *for 루프*를 추가하세요: `for (let i = 0; i < segments; i += 1) { }`
  - *for 루프*는 중괄호 안에 작성한 코드를 여러 번 반복합니다.
  - `circle()`을 그리는 코드 줄을 *for 루프*의 중괄호 안으로 이동하세요.
- for 루프 뒤에 추가하세요: `circX += spacing`
  - 이것은 `draw()`가 실행될 때마다 애벌레 몸체를 오른쪽으로 이동시킵니다.

코드는 다음과 같아야 합니다:

<EditableSketch code={`
// Set variables to draw the racetrack.
let startLine = 30;
let finishLine = 400;

// Set variables for the caterpillar.
let circX = startLine;
let circY = 250;
let spacing = 20;
let segments = 6;
let segmentSize = 50;

function setup() {
  createCanvas(500, 500);

  // Set a slow frame rate.
  frameRate(3);
}

function draw() {
  // Draw the background.
  background(121, 96, 76);

  // Draw the start and finish lines.
  noStroke();
  fill(0);
  rect(startLine, 0, 5, height);
  fill(0, 255, 0);
  rect(finishLine, 0, 20, height);

  // a local variable to position the body segments
  let x = circX;

  // draw multiple circles (caterpillar body)
  for (let i = 0; i < segments; i += 1) {
    // Draw a circle.

    fill(255);
    stroke(0);
    circle(x, circY, segmentSize);
    x += spacing;
  }

  // Move the caterpillar  to the right.
  circX += spacing;
  // stop the animation  when x
  // reaches the finish line.
  if (circX > finishLine) {
    noLoop();
  }
}
`} />


### [For 루프](/reference/p5/for)

for 루프는 코드의 한 섹션(또는 블록)을 여러 번 실행할 수 있습니다. for 루프는 다음과 같이 작성할 수 있습니다:

```js
for (let i = 0; i < number; i += 1) { 
  // number번 실행하고 싶은 코드
}
```

for 루프의 중괄호 `{}` 안에 반복적으로 실행하고자 하는 코드를 작성합니다. 루프의 조건을 설정하여 코드가 반복되는 횟수를 지정할 수 있습니다.

for 루프는 괄호 안의 세 개의 표현식으로 정의되며, 각각 세미콜론으로 구분됩니다:

<AnnotatedLine code={({ bottom }) => `for (${bottom('init', ' let i = 0; ')} ${bottom('cond', 'i < number;')} ${bottom('instr', '  i += 1  ')}) { }`}>
  <Fragment slot="init">초기화</Fragment>
  <Fragment slot="cond">조건</Fragment>
  <Fragment slot="instr">명령</Fragment>
</AnnotatedLine>

- **초기화**: 카운팅을 시작할 숫자로 반복 변수 `i`를 초기화합니다.

  ```js
  let i = 0;
  ```

- **조건:** 루프가 계속 실행되도록 하는 조건입니다. 이 조건이 참인 동안 for 루프는 계속 실행됩니다. 조건이 `false`가 되면 for 루프가 멈춥니다.

  ```js
  i < number;
  ```

- **명령:** 루프가 실행될 때마다 카운팅 숫자를 어떻게 변경할지 프로그램에 알려줍니다.

  ```js
  i += 1;
  ```

첫 번째 표현식 `let i = 0`은 for 루프를 초기화하거나 시작합니다.

- i는 for 루프의 초기 상태를 정의하는 변수입니다. *인덱스* 변수라고도 합니다. 일반적으로 인덱스는 0의 값으로 시작하며 각 루프마다 증가합니다. 이 변수의 이름은 원하는 대로 지정할 수 있습니다. 일반적으로 `i`, `j`, `k`와 같은 단일 문자 변수가 사용되지만, 더 설명적인 이름을 자유롭게 사용하세요.

두 번째 표현식 `i < number`는 루프가 계속 실행되는 조건입니다. 이 표현식은 `true` 또는 `false`를 반환할 수 있으므로 불리언 표현식이라고 합니다. 이 표현식이 `true`인 동안 for 루프는 계속 실행되며, 이 경우 인덱스 변수(`i`)가 계속 증가합니다.

- `number`는 숫자 값이나 숫자 값을 저장하는 변수가 될 수 있습니다. 카운팅에는 보통 정수가 사용됩니다.
  - 예: `i < 5;` 또는 `i < segments;`
- 이 경우 `number`는 초기 값 `i`가 0에서 시작하므로 for 루프가 실행되는 횟수를 결정합니다.
- 위의 애벌레 예제에서, 우리는 이 값을 `segments` 변수로 설정했으며, 이는 애벌레의 몸체를 구성하는 원의 수를 지정합니다. 인덱스가 `segments`에 저장된 숫자에 도달하지 않는 한 루프는 계속 원을 그립니다.
  - 그려진 원의 수가 더 이상 segments보다 작지 않으면, 프로그램은 for 루프를 종료하고 다음 코드 줄로 계속 진행합니다.

세 번째 표현식 `i += 1`은 각 루프 반복이 끝날 때 인덱스가 어떻게 변경되는지를 나타냅니다.

- [**루프 반복**](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Loops_and_iteration)은 루프가 한 번 실행되는 것을 의미합니다. 예를 들어, for 루프가 3번 실행되면 3번의 반복이 있습니다.
- 이 예에서 `i` 변수는 for 루프가 실행될 때마다 1씩 증가합니다. 즉, 이 for 루프가 처음 실행될 때 `i`는 0입니다. 두 번째로 루프가 실행될 때 `i`는 1입니다. 세 번째로 실행될 때 `i`는 2이며, 이런 식으로 계속됩니다(`number` 값에 도달할 때까지). 이 표현식 `i += 1`은 `i++`로도 작성할 수 있습니다.

요약하면:

1. 프로그램이 for 루프를 실행할 때, 먼저 첫 번째 표현식에서 루프의 인덱스 변수를 선언합니다.
2. 두 번째 표현식인 불리언 표현식을 확인합니다. 참이면 중괄호 안에 작성된 코드를 실행합니다.
3. 루프의 끝에서 반복 변수 `i`의 값은 세 번째 표현식에 정의된 대로 변경됩니다.
4. 루프는 두 번째 표현식의 조건이 `false`가 될 때까지 이 과정을 반복합니다. 조건이 `false`가 되면, 프로그램은 for 루프를 종료하고 스케치의 다음 코드 줄로 계속 진행합니다.

더 자세히 알아보려면 [for 루프 레퍼런스](/reference/p5/for)를 방문하세요.


### 3.3 – 애벌레에 더 많은 디테일 추가하기

- 원하시면 애벌레 몸체의 `fill()` 색상을 조정하세요. 이 예에서는 분홍색을 줄 것입니다: `fill(255, 0, 200);`
- 애벌레의 눈을 그리세요. 눈의 위치는 몸체에 대해 그려진 마지막 원의 x 및 y 좌표와 같습니다. 이것은 for 루프가 이미 모든 원을 그린 후에 온다는 것을 의미하므로, for 루프 뒤에 눈을 추가하되 `noLoop()` 전에 추가하겠습니다. 이렇게 하면 눈이 애벌레 몸체의 마지막 원 위에 그려집니다.
  - `setup()` 위에 `eyeSize`를 새 전역 변수로 선언하고 15의 값을 할당하세요.
  - 두 개의 원을 그리세요.
    - 검은색 채우기와 두꺼운 흰색 테두리를 주세요.
  - 첫 번째 눈을 추가하고 좌표와 크기를 설정하세요: `circle(x, circY-eyeSize, eyeSize);`
    - 이것은 마지막으로 그려진 원의 상단에 눈을 배치합니다.
  - 두 번째 눈을 추가하고 좌표와 크기를 설정하세요: `circle(x - eyeSize, circY-eyeSize, eyeSize);`
    - 두 번째 눈의 x 좌표에서 `eyeSize`를 빼서 두 눈이 겹치지 않고 나란히 있게 합니다.
- 애벌레가 완성되면, 코드를 `drawCaterpillar()`라는 커스텀 함수로 정리하세요. 애벌레를 원하는 대로 수정하세요!
  - `draw()` 밖에서 `drawCaterpillar()` 함수를 정의하세요.
  - 이 함수에는 애벌레 몸체를 위한 원의 for 루프와 애벌레 눈을 위한 두 개의 원이 포함되어야 합니다.
  - `draw()` 함수에서 호출하는 것을 잊지 마세요! 루프를 종료하는 if 문 앞에 `drawCaterpillar();`를 `draw()`에 입력하세요.

## 4단계 – `drawCaterpillar()` 함수 일반화하기

스케치가 처음 실행될 때, 각 애벌레가 출발선에 있기를 원합니다. 이것은 애벌레가 그려지는 위치를 지정하기 위해 함수에 매개변수를 추가해야 함을 의미합니다.

- `drawCaterpillar()` 함수로 이동하세요.
  - 함수의 괄호에 `x`를 매개변수로 추가하세요: `function drawCaterpillar(x) { ...}`
    - `drawCaterpillar()` 함수에서 이미 `x`를 로컬 변수로 선언했다는 점에 주목하세요. 해당 선언을 제거하고 대신 `x` 매개변수를 사용할 수 있습니다.
  - 함수의 괄호에 두 번째 매개변수로 `y`를 추가하세요 `function drawCaterpillar(x,y) { ... }`
    - 함수 본문에서 `circY`를 `y`로 대체하세요.

커스텀 함수, 인수, 매개변수에 대해 더 자세히 알아보려면 이전 튜토리얼 [함수로 코드 구성하기](/tutorials/organizing-code-with-functions)와 p5.js 레퍼런스의 [함수](/reference/p5/function)를 참조하세요.

## 5단계 – `drawCaterpillars()` 함수 만들기

이제 3마리의 애벌레가 동시에 화면을 가로질러 이동합니다. `drawCaterpillar()`에 대한 세 개의 개별 함수 호출 대신 루프를 사용하여 세 마리의 애벌레를 그릴 수 있습니다.

- 스케치에서 `setup()` 위에 경주에 원하는 애벌레 수에 대한 새 전역 변수를 선언하세요: `let numCaterpillars = 3;`
- `draw()` 밖에 새 커스텀 함수를 만들고 이름을 `drawCaterpillars()`로 지정하세요
  - `drawCaterpillars()` 함수 안에 새 for 루프를 만드세요.
    - 루프의 첫 번째 표현식에서 루프 변수를 0으로 초기화하고 시작하세요.
    - 루프의 두 번째 표현식에서 조건을 `i < numCaterpillars`로 설정하세요.
    - 세 번째 표현식에서 루프 변수를 증가시키세요.
  - for 루프의 중괄호 안에서 `drawCaterpillar(circX, circY);`를 호출하세요.
- `draw()`에서 `drawCaterpillars();`를 호출하세요

`draw()`와 `drawCaterpillars()` 함수는 다음과 같아야 합니다:

```js

  // Draw the start and finish lines.

  fill(0);
```

## 6단계 – 경주를 위해 애벌레 배치하기

**복습!** 3단계와 4단계에서, 스케치에 두 개의 커스텀 함수가 있습니다.

- `drawCaterpillar(x,y)`는 매개변수 x와 y를 사용하여 하나의 애벌레를 그립니다.
- `drawCaterpillars()`는 `drawCaterpillar()` 함수를 호출하고 여러 애벌레를 그릴 수 있도록 for 루프 안에 배치합니다.

현재 각 애벌레는 같은 x와 y 좌표에 있습니다. y 좌표를 사용하여 애벌레를 간격을 두고 배치하도록 for 루프의 코드를 조정하겠습니다.

- `drawCaterpillars()` 함수 선언으로 이동하세요.
  - *for 루프* 안에 새 코드 줄을 추가하세요: `let padding = height / numCaterpillars;`
    - 이것은 각 애벌레 사이의 수직 간격을 결정하는 `padding`이라는 새 변수를 선언합니다.
    - 캔버스의 `height`를 스케치에 있는 애벌레 수로 나눈 값을 할당합니다. 이렇게 하면 캔버스가 수직으로 행으로 나뉩니다(각 애벌레에 하나씩). 각 행의 높이는 `padding`의 값입니다.
  - 변수 `y`를 다음 값으로 초기화하세요: `let y = (i + 0.5) * padding`, 여기서 `y`는 각 애벌레의 y 좌표를 결정합니다.
    - `i` 변수를 사용하여, for 루프의 각 반복은 애벌레를 자신의 행에 배치합니다
    - `i`에 0.5를 더하면 애벌레가 해당 행의 중앙에 위치합니다.
- 5단계와 유사하게, `drawCaterpillar()` 함수 호출의 괄호에 `y`를 인수로 추가하세요.
  - 코드 줄은 이제 다음과 같아야 합니다: `drawCaterpillar(circX, y);`

요약하면, `drawCaterpillar()` 함수 안에서 사용할 매개변수로 `x`와 `y`를 할당했습니다. `drawCaterpillars()`에서 이 함수를 호출할 때 `circX`와 `y`를 인수로 사용합니다.

커스텀 함수, 인수, 매개변수에 대해 더 자세히 알아보려면 이전 튜토리얼 [함수로 코드 구성하기](/tutorials/organizing-code-with-functions)를 참조하세요.

지금까지 `drawCaterpillars()` 함수는 다음과 같아야 합니다:

```js
function drawCaterpillars() {
  for (let i = 0; i < numCaterpillars; i += 1) {
    let padding = height/numCaterpillars;
    let y = (i + 0.5) * padding;

    drawCaterpillar(circX, y, 6);
  }
}
```


### for 루프 인덱스 변수로 그리기

for 루프의 인덱스 변수(`i`)는 각 루프 반복마다 점진적으로 증가하거나 감소할 수 있습니다. 이 튜토리얼에서 `i` 변수는 0에서 시작하고 *for 루프*가 실행될 때마다 1씩 증가합니다.

- 이 for 루프가 처음 실행될 때, `i`는 0입니다.
- 두 번째로 루프가 실행될 때, `i`는 1입니다.
- 세 번째로 실행될 때, `i`는 2이며, 이런 식으로 계속됩니다.

그림에서 인덱스 변수를 사용하여 숫자를 더하고, 빼고, 곱하고, 나누어서 for 루프의 각 반복마다 결과가 다르게 할 수 있습니다.

이 예에서는 `i`를 사용하여 각 애벌레 사이의 일관된 간격을 계산합니다 (아래 표 참조):

- 첫 번째 반복 동안 `i`는 0이고 `y`는 `0.5 * padding`입니다. 첫 번째 애벌레가 해당 y 값으로 그려집니다.
- 두 번째 반복 동안 `i`는 1이고 `y`는 `1.5 * padding`이 됩니다. 두 번째 애벌레가 새로운 y 값에 그려집니다.
- 세 번째 반복 동안 `i`는 2이고 `y`는 `2.5 * padding`이 됩니다. 세 번째 애벌레가 새로운 y 값에 그려집니다.

전역 변수 `numCaterpillars`의 값을 변경하고 `drawCaterpillars()`의 for 루프가 캔버스에서 수직으로 어떻게 간격을 두는지 확인해 보세요.
</Callout>


## 7단계 – 각 애벌레의 위치를 저장할 배열 만들기

이제 캔버스에 애벌레를 수직으로 배치했으므로, 각각에게 고유한 x 좌표를 부여하고 싶습니다. 배열을 사용하여 이를 할 수 있습니다. 배열에는 각 애벌레의 x 좌표가 포함됩니다. 그런 다음 애벌레를 화면에서 무작위로 이동시켜 경주를 가능하게 할 수 있습니다.


### 7.1 – [배열](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) 만들기

- `numCaterpillars` 바로 뒤에 `caterpillarEnds` 배열을 선언하세요: `let caterpillarEnds = [];`
  - 이 배열은 각 애벌레의 가장 왼쪽 세그먼트의 x 위치를 보유합니다.


다음 튜토리얼 [데이터 구조 가든](/tutorials/data-structure-garden)에서 배열에 대해 더 자세히 배울 것입니다. 더 자세히 알아보려면 [배열](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)에 대한 MDN 레퍼런스를 방문하세요.

- `setup()`에서 각 애벌레의 x 좌표를 추가하여 모두 출발선에 배치하세요.
  - 각 애벌레에 대해 한 번 반복되는 for 루프를 만드세요: `for (let i=0; i < numCaterpillars; i++) { }`
  - 중괄호 안에 `caterpillarEnds.push(startLine);` 줄을 추가하세요
    - 이것은 스케치에서 그려야 할 각 애벌레에 대해 `caterpillarEnds` 배열에 `startLine` 값을 한 번 추가합니다.
    - `.push()` 메서드는 배열의 끝에 새 값을 추가하는 데 사용됩니다.

이제 `setup()`은 다음과 같아야 합니다:

```js
function setup() {
  createCanvas(500, 500);

  // Set a slow frame rate.
  frameRate(6);

  for (let i=0; i < numCaterpillars; i++) {
    //add the position of last segment into an array
    caterpillarEnds.push(startLine);
  }
}
```

- `drawCaterpillars()` 함수에서 `drawCaterpillar(circX,y)` 줄을 변경하세요:
  - `circX` 대신, 이제 `caterpillarEnds` 배열의 값을 사용하겠습니다.
  - for 루프의 인덱스 `i`가 `caterpillarEnds` 배열의 올바른 인덱스 위치를 나타내므로, `circX`를 `caterpillarEnds[i]`로 변경할 수 있습니다: `drawCaterpillar(caterpillarEnds[i], y);`
- 함수에서 `circX`를 제거하세요.
  - 참고: `circX`는 여전히 `draw()`의 끝에서 사용됩니다. 이것도 제거하고 나중에 다시 추가하겠습니다.

`drawCaterpillars()` 함수는 다음과 같아야 합니다:

```js
function drawCaterpillars() {
  for (let i = 0; i < numCaterpillars; i += 1) {  
    // Space between each caterpillar.
    let padding = height / numCaterpillars;
    let y = (i + 0.5) * padding;

    // Draw caterpillars using an array.
    drawCaterpillar(caterpillarEnds[i], y);
  }
}
```


### 7.2 – 애벌레를 무작위로 이동시키기

- `draw()` 밖에 새 커스텀 함수를 만들고 이름을 `moveCaterpillars()`로 지정하세요
- 애벌레 수만큼 반복하는 새 for 루프를 정의하세요: `for (let i = 0; i < numCaterpillars; i += 1) { }`
  - 이것은 `drawCaterpillars()` 함수에서 사용된 것과 같은 for 루프 구문으로, 각 애벌레를 개별적으로 참조할 수 있게 해줍니다.
- 루프 안에서 `move`에 로컬 랜덤 값을 할당하세요:

  ```js
  let move = random(5,30);
  ```

- 경주가 시작되면, `draw()`가 실행될 때마다 각 애벌레를 5에서 30 픽셀 사이에서 무작위로 오른쪽으로 이동시킵니다.
- 애벌레에 원하는 이동 범위에 따라 `random()`의 값을 수정할 수 있습니다. 더 자세히 알아보려면 [`random()`에 대한 p5.js 레퍼런스](/reference/p5/random)를 방문하세요.

함수는 다음과 같을 수 있습니다:

```js
function moveCaterpillars() {
  for (let i = 0; i < numCaterpillars; i += 1) {
    //Give each caterpillar a
    //random speed.
    let move = random(5, 30);
    caterpillarEnds[i] += move;
  }
}
```

요약하면, 위 함수에서의 이벤트 순서는:

- 각 루프 반복마다, `move`에 5에서 30 사이의 랜덤 숫자를 할당합니다.
  - 이는 모든 애벌레에 다른 랜덤 `move`가 할당됨을 의미합니다.
- 그런 다음 `caterpillarEnds` 배열의 `i`<sup>번째</sup> 위치의 값을 업데이트하며, 이것이 `drawCaterpillar()` 함수가 애벌레를 표시하는 데 사용하는 것입니다.

## 8단계 – 애벌레에게 기어가는 동작 부여하기

'기어가는' 움직임을 재현하기 위해, `random()` 함수를 사용하여 각 애벌레의 세그먼트 수를 무작위화하겠습니다. 복습하자면, 전역 `segments` 변수는 애벌레에 표시되는 세그먼트 수를 결정합니다. 이제 이것을 `drawCaterpillar()` 함수의 매개변수로 변경하겠습니다.

- `drawCaterpillar()` 함수 정의로 이동하세요.
  - `segments`라는 새 매개변수를 추가하세요. 이제 다음과 같아야 합니다: `function drawCaterpillar(x, y, segments) { ... }`
  - 스케치 상단의 `segments` 전역 변수를 제거할 수 있습니다.
- `drawCaterpillars()` 함수 정의로 이동하세요.
  - `drawCaterpillar()` 함수가 호출되는 괄호에 세 번째 인수로 `crawl`을 추가하세요: `drawCaterpillar(x, y, crawl);`
  - 이 줄 위에, `crawl` 변수에 새 랜덤 값을 할당하세요: `let crawl = round(random(3, 6));`
    - 이는 스케치가 실행되는 동안, 프로그램이 애벌레를 출발선에서 결승선으로 이동시키면서 지속적으로 랜덤 길이(3~6개의 원 사이)로 그린다는 것을 의미합니다.
    - 애벌레가 기어가는 길고 짧은 정도에 따라 `random()`의 값을 수정할 수 있습니다.
    - `crawl` 변수의 랜덤 값은 `drawCaterpillar()` 함수 정의의 `segments` 매개변수를 채우며, 이는 그려지는 원의 수를 결정합니다.

```js
    x += spacing;

  circle(x - eyeSize, y - eyeSize, eyeSize);
```

## 9단계 – 마우스 트리거로 경주 시작하기

- `isRacing`이라는 새 불리언 전역 변수를 선언하고 `false`로 설정하세요: `let isRacing = false`;
  - 이 변수는 애벌레가 경주 중인지 여부에 대한 정보를 불리언 값(`true` 또는 `false`)으로 저장하는 상태 변수로 작동합니다.
- `mousePressed()` 함수를 정의하세요.
  - 함수에서 `isRacing` 불리언을 `true`로 설정하세요.
- 함수는 다음과 같아야 합니다:

  ```js

  // user presses the mouse.
  function mousePressed() {
  ```

- `draw()` 함수에서 `drawCaterpillars()` 함수 호출 전에 새 if 문을 만드세요: `if (isRacing === true) { }`

## 10단계 – 경주의 시작과 끝에 메시지 추가하기

잘 하셨습니다! 스케치의 이 단계에서, 마우스 클릭으로 시작하는 애벌레 경주가 있습니다.

이제 프로그램 사용 방법에 대한 안내를 캔버스에 추가하기만 하면 됩니다. 경주 끝에 우승 애벌레를 발표하는 메시지도 추가하겠으며, 이는 무작위입니다. 우승자가 선언되면 경주가 끝나도록 noLoop() 함수를 다시 추가하겠습니다.


### 10.1 – 시작 메시지 작성하기

- `draw()` 뒤에 새 커스텀 함수를 만들고 이름을 `writeStart()`로 지정하세요.
- 함수 안에 추가하세요: `text(" 🏁 Click to start!", width / 2, height / 2);`
  - 이것은 안내 텍스트를 작성하고 캔버스 중앙에 배치합니다.
  - `text()` 명령 위에 `textAlign(CENTER);`를 추가하여 텍스트를 중앙 정렬하세요.
  - 텍스트에 스타일을 추가하세요. 이 예에서는 테두리 없이 흰색과 텍스트 크기 24를 부여하겠습니다.
- `writeStart()` 함수는 다음과 같아야 합니다:

  ```js
  function writeStart() {
  ```

- `draw()` 함수로 돌아가서 else 문을 추가하세요: `else {}`
  - 이 else 문은 경주가 아직 시작되지 않은 경우 실행됩니다
- 이 else 문 코드 블록 안에서 `writeStart()` 함수를 호출하세요.

`draw()` 함수는 다음과 같아야 합니다:

### 10.2 – 우승자 확인 및 누가 이겼는지 표시하기

애벌레 중 하나가 이겼는지 확인해야 합니다. 이긴 경우 해당 정보를 표시하고 경주를 종료해야 합니다.

- `draw()` 아래에 우승자를 확인하는 새 함수를 만드세요: `function checkWinner() {}`
- 함수의 중괄호 안에, 각 애벌레의 x 값을 확인하여 우승했는지 보는 for 루프를 작성하세요: `for (let i = 0; i < caterpillarEnds.length; i += 1) {}`
- for 루프 중괄호 안에, 각 애벌레가 결승선을 통과했는지 확인하는 if 문을 포함하세요: `if (caterpillarEnds[i] >= finishLine) {}`
- 이 if 문 안에서, 템플릿 리터럴을 사용하여 우승자를 동적으로 텍스트에 작성하세요:

  ```js
  text(`Caterpillar ${i + 1} wins!`, width / 2, height / 2);
  ```

  - 이것은 우승한 애벌레의 인덱스를 표시하는 텍스트를 동적으로 작성합니다. 인덱스는 0에서 시작하고 일반적으로 애벌레를 1부터 세므로 `i`의 값에 1을 더했습니다
  - 9.1단계와 유사하게, `textAlign(CENTER);`를 추가하여 텍스트를 중앙 정렬하고 텍스트에 스타일을 추가하세요.
- if 문 안에 `noLoop()` 함수도 포함하여 `draw()`의 실행을 중지하세요.

`checkWinner()` 함수는 다음과 같을 수 있습니다:

```js
function checkWinner() {
  for (let i = 0; i < caterpillarEnds.length; i += 1) {
    if (caterpillarEnds[i] >= finishLine) {
      // Style the text.
      textSize(24);
      textAlign(CENTER);
      fill(255);
      noStroke();

      // Display the message.
      text(`Caterpillar ${i + 1} wins!`, width / 2, height / 2);

      noLoop();
    }
  }
}
```
